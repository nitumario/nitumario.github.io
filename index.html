Personal Google Drive integration

Google Drive access for a personal computer.

Personal Drive Connector is a private Google OAuth application configuration used to authorize rclone, an open-source command-line file management tool, to access a Google Drive account at the account owner's request.

Personal use only. This website is informational. It does not provide a hosted file storage service, handle Google sign-ins, or receive files from your Google Drive. The actual connection runs locally through rclone on the user's device.

Browse and transfer

Use rclone to list folders, download, upload, copy, or move files between a personal computer and Google Drive.

Mount and synchronize

Mount Google Drive as a local folder, or manually synchronize selected files and folders with rclone.

User-controlled access

Authorization is granted through Google's OAuth consent flow. The user can revoke access through Google Account security settings.

Local operation

File transfers and OAuth credentials are managed by rclone on the user's own system, not by this website.

What access may be requested?

Depending on the rclone configuration, Google Drive permissions may include viewing file names, metadata and contents, as well as creating, updating and deleting Drive files. Full read/write access is needed for some mount and synchronization workflows. The specific permissions are shown on Google's consent screen before authorization.

How is your data handled?

Rclone contacts Google Drive directly to carry out the file operations initiated by the user. Files, cache data, logs and authorization tokens may be stored locally on the user's device. This website does not receive or store Google Drive files or OAuth tokens.
