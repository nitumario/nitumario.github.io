Privacy Policy

This policy explains how the Personal Drive Connector OAuth configuration is used with the locally installed rclone software to access Google Drive data.

1. Who operates this configuration

Personal Drive Connector is a Google OAuth project intended for private use by its owner with rclone. It is not a hosted cloud storage service or a public multi-user application. This website is an informational page for that OAuth project.

Contact about this OAuth configuration: nitu.mario@gmail.com.

2. Google data that may be accessed

After the user grants permission, rclone may access the Google Drive data needed for requested operations: file and folder names, identifiers, file metadata, folder structure, file contents, and other Drive information necessary to list, download, upload, mount or synchronize files. If the user authorizes read/write access, rclone may create, modify, move or delete files in Google Drive at the user's instruction or as part of a configured sync operation.

Permissions are limited to the OAuth scopes selected during rclone configuration and disclosed on Google's consent screen.

3. How Google data is used

Google Drive data is used only to perform the file operations the user configures in rclone, including browsing, transferring, mounting and synchronizing content. The website itself has no access to the user's Google Drive account.

Google user data obtained through Google APIs is used in accordance with the Google API Services User Data Policy and its Limited Use requirements. It is not used for advertising or sold to third parties.

4. Where files and credentials are stored

Rclone runs on the user's device and communicates with Google Drive through Google's API. Depending on the commands and settings the user selects, files and metadata may be downloaded into local folders, temporary caches or logs. Rclone configuration files may store OAuth access and refresh tokens locally so the user does not need to log in for every operation.

Local files, caches and tokens are protected by the user's own device and account security settings. They should not be assumed to be encrypted at rest unless the user has configured appropriate protections, such as rclone configuration encryption or full-disk encryption.

This website does not collect, upload, or store Google Drive files or OAuth tokens. It does not use advertising, analytics scripts, or application cookies. As with other static websites, the GitHub Pages hosting provider may process ordinary web request data under its own policies.

5. Sharing and transfers

This website does not sell or share Google Drive content with advertisers or data brokers. Rclone sends information to Google Drive to carry out the user's chosen operations. If the user explicitly configures another storage provider or destination in rclone, transferred files may also be sent to that user-selected destination. No such transfer is initiated by this website.

6. Retention and deletion

This website does not retain Google Drive data. Locally downloaded files, caches, logs and rclone configuration files remain on the user's device until deleted by the user or cleared according to the configured local software behavior. Deleting the local rclone configuration or cache does not necessarily delete files in Google Drive, and deleting a file in Google Drive does not necessarily remove a separate local copy.

7. Revoking access

The user can revoke the application's Google account access through Google Account third-party connections. The user may also remove the relevant rclone remote and locally saved OAuth credentials. Revoking access prevents further authorized API access but does not automatically delete files already downloaded to the device.

8. Security

OAuth authorization is handled through Google's authorization flow. The user is responsible for securing their computer and protecting any local files, logs, API credentials and rclone configuration. Rclone and Google each have their own security practices and terms.
