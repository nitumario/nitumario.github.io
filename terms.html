Terms of Service

These terms describe the intended use and limitations of the Personal Drive Connector Google OAuth configuration.

1. Purpose

Personal Drive Connector is a private Google OAuth project used to authorize rclone on the project owner's computer. The project is intended for personal file access and management, not as a hosted file-sharing or backup service for the public.

2. How it works

The website provides information about the OAuth configuration. File management is performed by the separately installed rclone software, which communicates with Google Drive using the permissions granted by the user. The website does not handle sign-in credentials, files or synchronization jobs.

3. Authorized use

The user must have authorization to access the Google account and files being managed, and must comply with applicable Google policies and laws. The user controls the rclone commands and any synchronization, transfer, deletion or mount settings used on their device.

4. File operations and risk

File transfers and synchronization can overwrite, move or delete data, particularly when using bidirectional sync or deletion options. The user should review commands and maintain suitable independent backups before performing destructive operations.
